# AI 프로그래밍 및 실습 프로젝트

수업에서 배운 머신러닝을 실제 금융 데이터에 적용한 프로젝트 두 개가 들어 있다.

| | ETF 지도 (발표용) | 주간 변동성 예측 |
|---|---|---|
| 질문 | 이름이 다른 ETF는 정말 다르게 움직일까 | 다음 주에 가격이 얼마나 크게 움직일까 |
| 노트북 | `etf_map.ipynb` | `volatility_forecast.ipynb` |
| 웹 | `docs/index.html` | `docs/volatility.html` |
| 수업 내용 | PCA, k-평균(6강), 분류 모델 비교, 교차 검증 | 회귀·트리·딥러닝 모델 비교, 시계열 분할 |

## ETF 지도

한국 상장 ETF 251개의 최근 2년(104주) 주간 수익률만 가지고 세 가지를 한다.

1. **군집화**: 표준화 → PCA(10개 축) → k-평균(k=10)으로 비슷하게 움직이는 ETF를 묶고 t-SNE로 지도를 그린다.
2. **분류**: 이름으로 붙인 테마 17개를 정답으로 두고 움직임만으로 맞힌다. 5-폴드 교차 검증으로 k-최근접 이웃, 로지스틱 회귀, 결정 트리, 랜덤 포레스트, 신경망을 비교한다.
3. **시장 국면**: 주(week)를 k-평균으로 상승·보합·하락으로 나누고 국면별 군집 수익률을 본다.

결과 요약 (2026-11-25 실행)

- 움직임만 보고 테마를 맞힌 정확도: 로지스틱 회귀 76.5%, 신경망 75.7%, 랜덤 포레스트 75.3% (가장 많은 테마로 찍으면 14.3%)
- 코스피·코스피200 ETF는 반도체 ETF와 같은 군집에 들어간다
- 커버드콜 ETF는 기초자산 ETF와 주간 수익률 상관계수가 0.99를 넘는다. 테마 정확도도 커버드콜이 가장 낮다(32%)
- 하락 국면(16주)에서 배당·가치 군집과 원유·농산물 군집만 평균 수익률이 0 이상이었다

테마는 ETF 이름의 단어로 붙인 것이라 완벽하지 않고, 기간이 달라지면 군집도 달라질 수 있다.

## 주간 변동성 예측

S&P 500, KOSPI, 금 ETF(GLD), 하이트진로의 다음 주 실현 변동성을 예측한다.

- 테스트 RMSE(로그 변동성): "이번 주 값 그대로" 기준선 0.569 → 상위 모델 0.455~0.460, 약 20% 감소
- 고변동 주간 분류: 로지스틱 회귀 AUC 0.79
- 하이트진로의 월별 변동성 차이는 p = 0.066으로 뚜렷하지 않았고, 계절 특성은 예측 성능을 거의 바꾸지 않았다

## 파일

| 파일 | 내용 |
|---|---|
| `etf_map.py`, `volatility_forecast.py` | 노트북 원본 (jupytext 형식, 수정은 여기서) |
| `etf_map.ipynb`, `volatility_forecast.ipynb` | 실행 결과가 들어 있는 노트북 |
| `build_notebook.sh` | 원본을 노트북으로 바꿔 실행하고 `docs/`의 데이터 파일을 갱신 |
| `data/` | ETF 목록, 야후 파이낸스에서 받은 시세 |
| `docs/` | 웹 페이지. 서버 없이 `docs/index.html`을 브라우저로 열면 된다 |

## 실행

```bash
pip install -r requirements.txt
```

```bash
./build_notebook.sh etf_map
```

인자를 빼면 두 노트북을 모두 다시 만든다. ETF 시세를 새로 받으려면 `etf_map.py`의 `REFRESH`를 `True`로 바꾼다.

GitHub Pages로 공개하려면 저장소 Settings → Pages에서 브랜치의 `/docs` 폴더를 지정한다.

두 프로젝트 모두 과거 데이터 분석이며 투자 권유가 아니다.
