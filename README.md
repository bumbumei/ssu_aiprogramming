# 주간 변동성 예측

AI 프로그래밍 및 실습 프로젝트. 이번 주까지의 일별 시세로 **다음 주 변동성**을 예측한다.
대상은 S&P 500, KOSPI, 금 ETF(GLD), 하이트진로 4개다.

주가의 방향(상승·하락)은 예측하기 어렵지만 변동성은 클 때 계속 크고 작을 때 계속 작은 성질이 있어 예측할 수 있다.

## 구성

| 파일 | 내용 |
|---|---|
| `volatility_forecast.ipynb` | 실행 결과가 들어 있는 노트북 (데이터 → 특성 → 모델 비교 → 예측) |
| `volatility_forecast.py` | 노트북 원본 (jupytext 형식, 수정은 여기서) |
| `build_notebook.sh` | 원본을 노트북으로 바꿔 실행하고 `docs/data.js`를 갱신 |
| `data/prices.csv` | 야후 파이낸스에서 받은 일별 시세 (다운로드가 안 될 때 사용) |
| `docs/index.html` | 웹 대시보드. `docs/data.js`를 읽는다 |

## 실행

```bash
pip install -r requirements.txt
```

```bash
./build_notebook.sh
```

노트북을 직접 열어 위에서부터 실행해도 된다. 마지막 셀이 `docs/data.js`를 만든다.

웹 대시보드는 `docs/index.html`을 브라우저로 열면 된다. 서버가 필요 없다.
GitHub Pages로 공개하려면 저장소 Settings → Pages에서 브랜치의 `/docs` 폴더를 지정한다.

## 방법

- **타깃**: 다음 주 실현 변동성(일별 로그수익률 제곱합의 제곱근)의 로그값
- **특성**: 과거 변동성(1~3주 전, 4·12·52주 평균), 고가-저가 범위, 수익률, 거래량, VIX, 환율 변동성, 계절, 자산 구분
- **분할**: 시간 순서. 훈련 ~2017 / 검증 2018~2020 / 테스트 2021~
- **모델**: k-최근접 이웃, 선형·릿지·라쏘, 결정 트리, 랜덤 포레스트, 그레이디언트 부스팅, DNN, 1D CNN, LSTM
- **기준선**: 이번 주 변동성 그대로, 최근 4주 평균
- **분류**: 다음 주가 고변동 주간(자산별 상위 30%)인지 로지스틱 회귀 등으로 예측

## 결과 요약 (2026-11-25 실행)

- 테스트 RMSE(로그 변동성): 기준선 0.569 → 상위 모델 0.455~0.460, 약 20% 감소
- 랜덤 포레스트, 라쏘, DNN, 릿지, LSTM, 그레이디언트 부스팅이 거의 같은 성능이다
- 고변동 분류: 로지스틱 회귀 AUC 0.79, 정확도 0.79
- 월별 변동성 차이는 S&P 500, KOSPI, 금에서 유의했고(p < 0.05) 하이트진로는 p = 0.066이었다.
  계절 특성을 넣어도 예측 성능은 거의 달라지지 않았다

이 프로젝트는 변동의 크기만 예측하며 투자 권유가 아니다.
